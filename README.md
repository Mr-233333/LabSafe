# 高校实验室安全助手：支持挂机刷时长和导出试卷自动答题

LabSafe 在高校实验室安全教育平台的页面右下角提供课程播放、累计学时、试卷导出和答案导入工具。导入答案后，脚本可按题号、题干和选项匹配并填写判断题和选择题。

## 功能

- **课程播放**支持静音、倍速和播完后切到下一课，可选在图文学习达标后切课。
- **累计学时**显示平台记录的学时，支持手动刷新。学时以平台服务器记录为准。
- **空闲提示**由脚本识别并处理，便于继续当前页面的学习。
- **试卷导出**将当前页或整套试卷的题干和选项保存为 TXT，图片用 `[图片]` 表示。
- **自动答题**在浏览器本地读取 TXT 或 JSON 答案文件，检查匹配情况后，由用户触发填写。交卷由用户自行操作。
- **诊断日志**支持自检、复制和下载，方便排查学时读取或播放问题。

## 安装与使用

1. 安装 Tampermonkey 等用户脚本管理器，再安装本脚本。
2. 登录学校的实验室安全教育平台。脚本在路径包含 `lab-study-front`、`lab-platform` 或 `cg-exam` 平台路由的网页运行，可用功能取决于学校的平台版本和页面结构。
3. 打开一节课程，在右下角面板点「开始」，按需设置倍速、自动切课和图文学习。面板显示平台记录的累计学时，浏览器后台限频可能延迟播放和刷新。

## 考试与练习功能

### 1. 导出试卷

进入已经显示题干和选项的答题页。脚本识别题目后，右下角面板会显示导出和答案工具。

- 点「仅当前页」可立即下载当前页的题目。
- 点「导出全部题目 TXT」可尝试返回首页，再按页面的「下一页」逐页导出。建议从第一页开始，并在下载后核对 TXT 顶部的页数、题数和提示。
- 导出时可以点「停止并保存」，保留已经采集的部分。遇到无法识别的翻页控件时，可手动切页后使用「仅当前页」。

导出文件包含当前浏览器已加载的题干和选项。遇到 `[图片]` 时，请回到原页面查看题图。需要自动填写时，请另行准备答案文件。

### 2. 准备答案文件

点「本页答案模板」会下载带题号和题干的 TXT。把每行的 `?` 改成你准备的答案，保留 `|` 后的原题干。随机抽题或改卷后，脚本可以用题干发现题号相同但内容不同的情况。

**TXT 示例**

```text
1=对|进入实验室前应了解应急出口的位置。
2=B
3=ACD
4=?
```

判断题用 `对` 或 `错`，单选题用一个字母，多选题和不定项选择题可用 `ACD` 这样的字母组合。`?` 表示跳过。只写题号和答案时，脚本按题号和选项匹配。

**JSON 示例**

```json
{
  "1": { "answer": "对", "stem": "进入实验室前应了解应急出口的位置。" },
  "2": "B",
  "3": "ACD",
  "4": "?"
}
```

### 3. 导入、检查与填写

1. 点「导入答案 TXT / JSON」，选中本地答案文件。文件大小上限为 1 MB。
2. 查看导入后的提示，也可点「检查匹配」重新对照当前页。面板会显示可匹配、已一致、缺答案、不匹配的题数。「其他页答案」表示文件中的这些题号未出现在当前页。
3. 点「填写当前页」只处理当前页。点「填写整套题」会尝试返回首页，并通过页面按钮逐页填写。
4. 默认保留页面已有选择。确实需要替换时，先勾选「允许覆盖已选」。执行中可以点「停止填写」，已完成的选择仍保留。
5. 完成后查看「需人工核对」的项目，确认页面实际勾选情况。填空题、简答题以及题干或控件匹配失败的题目由用户处理，交卷也由用户操作。

### 常见问题

| 提示或现象 | 处理方法 |
| --- | --- |
| 面板里没有试卷工具 | 进入题干与选项都已显示的实际答题页，等待面板识别。 |
| 题干不一致或匹配数量偏少 | 检查是否重新抽题，按当前页重新导出并核对本地答案文件。 |
| 翻页中断或导出题数偏少 | 手动切页，分别使用「仅当前页」或「填写当前页」。 |
| 已选答案没有替换 | 检查「允许覆盖已选」，然后根据当前页的匹配提示决定是否重新填写。 |

## 隐私与数据

- 学时查询通过当前登录的学校平台发出，只使用预设的学时查询请求。
- 试卷、答案模板和诊断文件由浏览器本地生成。导入的答案在当前页面处理。
- 诊断日志记录页面类型、操作计数和状态。试卷里的图片用占位符表示，避免写入可能含凭证的图片地址。
